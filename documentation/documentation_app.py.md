This `app.py` file is the **"Visual Dashboard"** (the Face) of your application.

While the FastAPI server acts as the central hub, Streamlit provides the high-level user interface. Its job is to handle file uploads, display the chat bubbles, and render the statistical plots generated by your R scripts.

---

* **`st.set_page_config`**: Forces the app to use the full width of the screen, which is essential for viewing wide genomic datasets and side-by-side plots.
* **`fetch_ai_response`**: This is the "Postman." It takes whatever the user types and shoots it over to your FastAPI server (Port 8000).

### 2. Assets & Branding (The Header)

This section injects your custom identity into the application.


* **Dynamic Loading**: It checks if the files exist before trying to display them. This prevents the app from crashing if you haven't uploaded your `banner.jpeg` yet.

### 3. The Chat Column (Interactive Logic)

Streamlit uses "Session State" to remember what was said previously, as the script reruns from top to bottom every time you click a button.

```python
with chat_col:
    if "messages" not in st.session_state:
        st.session_state.messages = [{"role": "assistant", "content": "Hi there! ..."}]

    if prompt := st.chat_input("Ask me to analyze your trial data..."):
        # Display user message, call fetch_ai_response, display AI reply

```

* **`st.session_state`**: Acts as the "memory" of the browser tab. Without this, your chat history would disappear every time the AI finished an analysis.
* **`st.spinner`**: Provides visual feedback ("Analyzing...") so the user knows the R-script is working in the background.

### 4. The Workspace Column (File Management)

This is the most functional part of the UI. It bridges the gap between the user's local computer and the server's hard drive.

```python
with workspace_col:
    uploaded_file = st.file_uploader("Upload a new dataset here:", type=["csv", "xlsx"])
    if uploaded_file is not None:
        file_path = os.path.join(WORKSPACE_IN, uploaded_file.name)
        with open(file_path, "wb") as f:
            f.write(uploaded_file.getbuffer())

```

* **File Uploader**: When a user drops a file here, the script physically writes that file into `/workspace/inputs/`. This is what allows the AI agent to "see" the data you just uploaded.
