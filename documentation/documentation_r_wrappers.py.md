This `r_wrappers.py` file is the **"Physical Interface"** of your application. It acts as the bilingual translator that allows your modern Python-based AI to speak the language of professional R-based biometrics.

Because Python is great at "thinking" (logic) and R is great at "doing" (complex math), this file bridges the two worlds so you can have the best of both.

---

### 1. The Bilingual Bridge (`rpy2`)

This section sets up the communication line between Python and R.

```python
import rpy2.robjects as robjects
from rpy2.robjects import pandas2ri
from rpy2.robjects.packages import importr

# Enable automatic conversion between R data.frames and Pandas DataFrames
pandas2ri.activate()

```

* **`rpy2`**: This is the magic library that allows an R session to run *inside* your Python process.
* **`pandas2ri.activate()`**: This is critical for data science. It ensures that when you load a CSV in Python (Pandas), it is automatically converted into a format that R functions understand (DataFrames), and vice versa.

### 2. The Absolute Workspace Control

This section prevents the "File Not Found" errors that plague most AI agents by forcing every file to live in a specific, absolute location on the hard drive.

```python
R_DIR = "/content/PlantbreedAIAgent/core_logic/r_package/plantbreeding/R"
INPUT_DIR = "/content/PlantbreedAIAgent/workspace/inputs/"
OUTPUT_DIR = "/content/PlantbreedAIAgent/workspace/outputs/"

def get_input_path(file_path: str) -> str:
    """Forces the file path to securely look in the absolute inputs folder."""
    if not file_path.startswith("/content"):
        clean_filename = os.path.basename(file_path)
        return os.path.join(INPUT_DIR, clean_filename)
    return file_path

```

* **`get_input_path`**: This is a "Path Sanitizer." Even if the AI agent just says "Look at data.csv," this function automatically wraps it in the full, secure path `/content/.../workspace/inputs/data.csv`.

### 3. The R-Script Importer

At the very start, the script "teaches" Python how to do plant breeding by importing all your specialized `.R` files.

```python
scripts = [
    'simulate_field_trial.R', 'generate_rcbd_plan.R', ... 'AUDPC.cal.r'
]

for script in scripts:
    robjects.r['source'](os.path.join(R_DIR, script))

```

* **`robjects.r['source']`**: This command reads your R code and stores the functions (like `analyze_rcbd`) into Python's memory. Once this loop finishes, Python "knows" how to perform every analysis in your catalog.

### 4. The `@tool` Wrappers (The AI's Skills)

Each function in this file represents a single "skill" that the AI can perform. The `@tool` decorator tells LangChain to describe this function to the AI.

```python
@tool
def analyze_rcbd_comp_tool(data_csv: str, trt_col: str, blk_col: str, resp_col: str) -> str:
    """Performs comprehensive RCBD ANOVA, Tukey HSD, and Permutation Power."""
    try:
        df = pandas2ri.py2rpy(pd.read_csv(get_input_path(data_csv)))
        grdevices.pdf(f"{OUTPUT_DIR}RCBD_Analysis.pdf")
        robjects.globalenv['analyze_rcbd'](df, trt_col, blk_col, resp_col)
        grdevices.dev_off()
        return "Comprehensive RCBD analysis plots generated."
    except Exception as e: safe_dev_off(); return f"Error: {e}"

```

* **`grdevices.pdf(...)`**: This opens a virtual "canvas." Any plot generated by R in the next line is drawn onto this PDF file instead of being lost.
* **`robjects.globalenv['...']`**: This is Python actually reaching into the R engine and pulling the trigger on the statistical calculation.
* **`safe_dev_off()`**: This is the custom safety feature we added to ensure the graphics engine closes correctly, even if the math crashes, preventing "null device" errors.
